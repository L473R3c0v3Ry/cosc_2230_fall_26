#+begin_src java :eval never :tangle ../src/SlowReverse.java
  // SlowReverse.java: reverse1() from Exercise 4.1.19
  public class SlowReverse
  {
      public static String reverse(String s)
      {
          String r = "";
          for (int i = 0; i < s.length(); i++)
              r = s.charAt(i) + r;
          return r;
      }
  }
#+end_src

#+begin_src java :eval never :tangle ../src/RandomString.java
  // RandomString.java: n random lowercase letters
  public class RandomString
  {
      public static String make(int n)
      {
          char[] a = new char[n];
          for (int i = 0; i < n; i++)
              a[i] = (char) ('a' + StdRandom.uniformInt(26));
          return new String(a);
      }
  }
#+end_src

* Exercises

1. Strings are immutable, so =s.charAt(i) + r= copies all of =r= into a
   new string. Show that =SlowReverse= writes n(n+1)/2 characters in
   total. What is its order of growth?

2. Write =FastReverse.java= with a linear-time =reverse(String s)=, using
   a =char[]= and =new String(char[])=. The book prints an answer: write
   yours first, then compare. Add a =main= that checks it against
   =SlowReverse= with =equals()= for lengths 0, 1, 2, 10 and 1000.

3. Write =ReverseTest.java=, a doubling test in the style of
   =DoublingTest=: =java -cp .:stdlib.jar ReverseTest slow|fast start max=
   prints n, the time and the ratio to the previous time. Build the
   string before starting the =Stopwatch=.

4. Predict the ratio, then run =ReverseTest slow 25000 400000= and
   =ReverseTest fast 1000000 32000000=. Compare. From your slow time at
   n = 400,000, predict the time at n = 1,000,000.

5. Argue that no algorithm can reverse a string in less than linear
   time.
